## 📌 Executive Summary
An end-to-end commercial sales performance analytics engine and interactive web dashboard developed to analyze **1,250+ transactional records**. Cleaned raw sales datasets using Python (`Pandas`, `NumPy`), structured relational schemas, and evaluated core business KPIs achieving **$1.49M Net Revenue** with a **20.7% Profit Margin**.

## 🚀 Key Features & Business Insights
- **1,250+ Transactional Records Cleaned**: Standardized currency, calculated multi-tier discounts, and handled missing values across product categories and global sales regions.
- **KPI Reporting**: Built interactive metric tracking for **$1.49M Revenue**, **$308.4K Profit**, and **20.70% Profit Margin**.
- **High-Discount Margin Erosion Engine (≥25% Threshold)**: Pinpointed 120 high-discount orders causing heavy profit margin decay (compressing margin from 28.5% down to 8.4%).
- **Strategic Bundling Insights**: Discovered that pairing SaaS Enterprise Licenses with Ergonomic Furniture drives a **+14% revenue lift**.
- **Interactive Multi-dimensional Web Dashboard**: Live filtering across Region, Product Category, and Discount Erosion thresholds powered by Chart.js.

## 🛠️ Tech Stack & Skills
- **Data Engineering & Analysis**: Python (`Pandas`, `NumPy`), SQL (`MySQL`), Microsoft Excel (`VLOOKUP`, `Pivot Tables`).
- **Data Visualization & BI**: PowerBI (`DAX`, Modeling, Slicers), Chart.js, HTML5, CSS3, JavaScript.
